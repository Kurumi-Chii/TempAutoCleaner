# 产品需求与开发规范

**需求版本** 1.0 Draft  
**目标版本** V1.0.0  
**许可证** MIT

## 产品与平台

Temp Auto Cleaner 是免费开源的 Windows 工具。当前用户登录后延迟 30 秒运行，清理符合条件的临时文件、生成本地报告，然后退出。正常运行静默，无控制台、普通成功通知、托盘图标或重复失败弹窗。无需管理员权限、后台常驻进程或 Windows 服务。程序无广告、遥测、日志上传及自动联网更新。

使用 C#、.NET Framework 4.8、Windows Task Scheduler、Inno Setup、Git、GitHub 及 GitHub Actions。首要目标为 Windows 10 22H2 x64，次要目标为 Windows 11 x64。V1.0 的正式支持范围排除 Windows 7、8、32 位和 ARM64。正式发布前完成真实系统兼容性测试。

## 清理规则

- 目标固定为当前用户的 %LOCALAPPDATA%\Temp。使用当前用户身份动态解析，验证根目录及路径。根目录缺失、路径异常或遇到重解析点时安全退出或跳过，始终保留 Temp 根目录。
- 普通文件的创建时间和最后修改时间必须都严格超过 24 小时。只允许删除能够确认位置、属性和时间、且当前进程有权删除的文件。删除前再次验证状态和对象身份，考虑文件或目录在扫描与删除之间被替换的情况。
- 递归处理普通子目录，先处理文件。仅尝试删除已经为空且创建和修改时间均超过 24 小时的子目录。保留含有新文件、占用文件或其他不能删除内容的目录。
- 跳过符号链接、联接点、其他重解析点和状态不明的对象。遇到占用、权限不足或路径消失时记录状态并尽可能继续处理同级对象。路径安全性无法确认时终止该范围内的清理。
- 清理使用普通权限。保持系统权限及文件占用状态，禁止强制结束其他软件或解除占用。Dry Run 用于验证清理判断，保留清理目标。

## 本地报告

报告保存在 %LOCALAPPDATA%\TempAutoCleaner\logs，字段名和结构与系统语言无关。记录开始和结束时间、成功或部分成功或失败的状态、删除及跳过的文件数、已删除文件的字节数估算及必要的非敏感错误代码。报告省略完整个人路径，按默认 30 天保留期安全轮换。字节数是估算，磁盘可用空间可能以不同幅度变化。

## 安装版与便携版

Inno Setup 安装界面根据系统语言选择简体中文或英文，其他语言使用英文。安装说明解释清理行为。安装至当前用户目录并检查运行环境，安装核心程序后创建、验证当前用户的任务。任务仅在指定用户登录后延迟 30 秒触发，使用当前用户普通权限，禁止并发运行，每次只运行一轮。安装完成时不执行清理，首次自动执行在下一次登录。安装失败时尽可能回滚新文件及任务。

升级与卸载正确处理相关任务和正在运行的实例。卸载禁用并删除对应任务，再移除安装文件，默认保留日志供用户自行处理。仅操作本程序的文件和任务。

便携版以独立 EXE 提供，手动运行一轮后退出，默认不创建计划任务。它与安装版共用核心和日志，仅需 .NET Framework 4.8 运行环境。

README 与使用说明提供简体中文（zh-CN）和英语（en-US）。中文用户名、Unicode 路径与文件名均需正确处理。

## 阶段与发布验收

| 阶段 | 目标 |
| --- | --- |
| V0.1.0-alpha | 初始化项目，实现清理核心、日志和 Dry Run，以隔离测试验证基本安全规则。 |
| V0.9.0-beta | 实现登录任务和双语安装程序，提供便携包，测试安装、升级、卸载，开始 Windows 10/11 兼容性测试。 |
| V1.0.0 | 通过关键安全及兼容性验收，修复已知问题，完善双语文档，验证自动构建和发布流程。 |

关键验收覆盖双时间戳和阈值、占用、权限、空目录、路径消失和替换、异常时间、错误根目录、重解析点、Dry Run 及根目录外哨兵保护。系统验收覆盖 Windows 10 22H2 x64 与 Windows 11 x64，验证登录延迟、单实例、静默运行和退出。安装验收覆盖全新安装、回滚、下次登录首次执行、升级、卸载、计划任务清理和便携运行。国际化验收覆盖中英文系统、中文用户名、Unicode 名称和安装卸载界面。

GitHub Actions 编译、执行隔离测试并生成构建产物。发布包含 TempAutoCleaner-Setup-x64.exe、TempAutoCleaner-Portable-x64.zip、SHA-256 校验文件和中英文版本说明。稳定发布须由人工确认，且所有关键安全测试通过，已知越界删除或误删问题均须解决。

## 开发边界

先实现并测试安全清理核心，与任务调度和安装程序集成保持隔离。优先标准库和少量依赖。所有自动化测试使用独立测试目录，保留全部安全保护。每阶段报告变更及测试结果，遇到需求冲突说明问题和备选方案。访问真实 Temp 执行删除、推送 GitHub 或发布 Release 均需明确授权。

V1.0 的范围限于单用户 Temp 清理。可视化主界面、常驻托盘、云同步、遥测、自动更新、多用户清理及浏览器缓存、注册表和其他系统目录清理均在范围之外。
